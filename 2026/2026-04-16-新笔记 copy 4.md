5. 这个 Exp3 会不会一定比 Exp2-A 好？

不一定。

这是我们必须提前接受的。

原因有三点：

第一，固定 prompt 是粗粒度方向语义，而 gaze 是连续角度回归。

第二，CLIP 的语言-视觉对齐更擅长语义类别，不一定擅长眼部细微几何。那篇 VLM gaze controlled study 发现，多数视觉语言模型在人类 gaze referential inference 上接近随机，强模型也可能更多依赖头部方向而不是眼睛方向。 ￼

第三，你的 prompt 是人工固定句子，不是 CoOp 那种可学习 prompt，也不是 CLIP-Gaze / LG-Gaze 那种针对 gaze 任务设计的复杂语言约束。CLIP-Gaze 不是简单用“looking left/right”，而是用语言描述 gaze-irrelevant factors，例如外貌、佩戴物、图像质量等，并用这些文本特征帮助分离 gaze-relevant feature。 ￼
所以 Exp3 的论文预期应该是：
如果提升：说明固定方向 prompt 对 gaze 回归有辅助价值。
如果不提升：说明粗粒度固定 prompt 对连续 gaze regression 支持有限，后续需要连续 prompt / learnable prompt / geometry-aware prompt。
