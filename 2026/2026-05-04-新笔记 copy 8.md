第一阶段：复现一个高质量 RAG/Agent 项目

目标是快速跑通主流程。

你可以找这些类型的项目：
	•	PDF 问答 RAG；
	•	LangChain RAG tutorial；
	•	LlamaIndex research assistant；
	•	Agentic RAG；
	•	AutoGen / CrewAI / LangGraph agent workflow；
	•	带 citation 的论文问答系统。

这个阶段不要纠结“原创性”，重点是知道系统怎么跑起来。

你要边复现边记笔记：
	•	每个模块做什么；
	•	输入输出是什么；
	•	哪些地方可以替换；
	•	哪些地方容易出错；
	•	哪些参数影响效果。

面向 AI 论文和个人学习资料的 RAG-Agent 学术助手

面向视觉语言模型论文的 RAG-Agent 研究助手

它就不再是普通 PDF 问答，而是你的个人技术方向项目。

第三阶段：加入“面试加分模块”

这些模块会显著提高项目含金量：
	1.	引用溯源 citation grounding
回答必须显示来自哪篇文档、哪一段。
	2.	chunking 对比实验
比较不同 chunk size / overlap 对检索效果的影响。
	3.	embedding 模型对比
比如 OpenAI embedding、本地 bge/m3e/e5 embedding。
	4.	reranker 模块
初检 top-k 后再用 reranker 重排。
	5.	RAG evaluation
评估 retrieval precision、faithfulness、answer relevance、citation accuracy。
	6.	拒答机制
当资料中没有答案时，系统应该说“不知道”，而不是编。
	7.	Agent workflow
例如：
	•	搜索相关论文；
	•	读取摘要；
	•	提取方法；
	•	生成对比表；
	•	总结研究 gap。
	8.	可视化界面
Streamlit 就够，不必一开始做复杂前端。

这些才是你真正自己的部分。
你的原创性应该放在：
	1.	场景原创：面向学术论文/AI 论文/视觉语言模型学习资料；
	2.	数据原创：你自己整理论文、课程笔记、毕设资料；
	3.	流程原创：设计 research assistant workflow；
	4.	评估原创：设计测试问题集和指标；
	5.	分析原创：比较 chunking、embedding、reranker、prompt 的影响；
	6.	表达原创：README、技术博客、简历项目经历写得清楚。
